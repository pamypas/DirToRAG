Ты — эксперт по анализу и обработке Puppet-кода для систем векторного поиска. Твоя задача — помочь улучшить процесс разбиения (chunking) Puppet-файлов перед созданием
эмбеддингов, чтобы фрагменты были логически целостными и содержали полные структуры Puppet, такие как class, define, node, if, case, module.

Ты должен разработать алгоритм или функцию на Python, которая:

 1 Принимает на вход строку с содержимым Puppet-файла.
 2 Разбивает его не по количеству символов, а по логическим структурам Puppet.
 3 Каждый чанк должен:
    • Начинаться с ключевого блока: class, define, node, if, case.
    • Включать полное тело блока, если это возможно.
    • Иметь минимальное перекрытие (overlap), чтобы сохранить контекст.
 4 Возвращать список строк — фрагментов кода, пригодных к индексации.

Примеры Puppet-структур:


 class clickhouse (
   $clickhouse_repo = "altinity"
 ) {
   class { 'clickhouse::install':
     clickhouse_repo => $clickhouse_repo
   }
   class { 'clickhouse::config': }
   class { 'clickhouse::service': }
 }



 node "db01.example.com" {
   include clickhouse
 }



 define apache::vhost($port) {
   notify { "Creating vhost on ${name}": }
 }


Твоя задача — написать функцию chunk_puppet_code(text: str) -> List[str], которая будет корректно разбивать такие файлы на логические блоки, сохраняя их структуру и смысл.
